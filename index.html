先接上信箱

大家的願望信要存在一個共用的地方。這個網頁用免費的 Firebase 當信箱，主辦人設定一次就好。參加者請向主辦人索取完整的分享連結。

  1. 用 Google 帳號登入 console.firebase.google.com，按「建立專案」，名稱隨意，Google Analytics 可以關閉。
  2. 左側選單點「Build」，再點「Realtime Database」，按「建立資料庫」。位置選 Singapore，安全性規則選「以測試模式啟動」。選項名稱可能和這裡略有不同。測試模式約 30 天有效，辦完活動後可以直接刪除專案。
  3. 資料庫頁面上方有一串網址，長得像 https://專案名-default-rtdb.…firebasedatabase.app。複製後貼到下面。

目前是直接開檔案。要讓朋友使用，請先把這個檔案放到網路上（例如 Netlify Drop 或 GitHub Pages），再用那個網址開啟這一頁。
